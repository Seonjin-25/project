# 현장별 공정·기성 대시보드 PRD

## 한눈에 보기

- 본사 공무팀 담당자가 매달 12개 가상 현장의 공정·기성을 비교하는 PC 웹 앱입니다.
- 현장별 엑셀을 하나씩 비교하는 시간을 줄입니다.
- 첫 화면에서 전체 지표를 먼저 보고, 점검 현장과 월별 변화·기록을 확인합니다.
- 자료 가져오기, 현황 조회, 점검 현장 확인, CSV 내보내기, AI 설명을 제공합니다.
- 교육용 자료와 검산표를 기준으로 로컬 구현·검증까지 진행합니다.

| 줄일 불편 | 현장별 엑셀을 하나씩 비교하는 시간 | 질문 2에서 선택 |

## 자료와 해석 기준

| 항목 | 요구사항·근거 |
|---|---|
| 범위 | 현장 A~L 12곳 × 2025년 10월~2026년 9월, 144행·15개 열. CSV와 JSON은 같은 자료 |
| 현장 정보 | 현장명·지역·유형·계약금액·착공일·계약상 준공일을 사용 |
| 월별 정보 | 계획·실제 공정률, 누적기성액, 주요 공종, 특이사항 분류, 상황·대응 계획을 사용 |
| 자료 성격 | 교육용 가상 자료임을 표시. 실제 회사의 현장·실적으로 소개하지 않음 |
| 해석 주의 | 기성률은 금액 기준, 실제공정률은 공정 기준. 누적기성액은 수금액이 아님 |
| 기록의 의미 | 기록된 상황과 계획된 대응을 구분. 대응 완료나 효과를 임의로 확정하지 않음 |
| 기준 문서 | 단위·계산·예상값은 `data/데이터설명.md`, `data/검산표.md`를 따름 |

## 만들 기능

| 기능 | 제품 요구사항 | 필요한 이유 |
|---|---|---|
| 자료 가져오기 | CSV·JSON의 필수값·숫자 범위·중복·날짜·현장 정보 일관성·누적값 등을 검사하고 미리보기 후 전체 교체. 오류·취소 시 기존 자료 유지 | 잘못된 자료 반영과 중복 누적 방지 |
| 검사 결과 | 오류 행·항목·이유 표시. 월별 누락은 경고하고 확인 가능한 행만 집계했음을 안내 | 사용자가 자료 문제를 판단 |
| 공통 필터 | 월·지역·공사 유형·현장 선택. 현황·차트·표·CSV·AI에 동일 적용. 지역·유형 변경으로 현장이 범위를 벗어나면 현장 선택을 전체로 변경 | 결과 간 범위 불일치 방지 |
| 전체 현황 | 첫 자료 반영 후 2026년 9월·전체 현장 표시. 기성률·계획공정률·실제공정률·공정차이의 큰 숫자 4개를 우선 표시 | 사용자 선택 3 반영 |
| 월별 추이 | 같은 지역·유형·현장의 시작 월부터 선택 월까지 계획·실제 공정률과 월별 기성액 표시 | 현재 상태와 변화 방향을 함께 확인 |
| 점검 순위 | 공정차이가 작은 순, 같으면 현장 ID 순. 공정차이와 계획·실제 공정률·기성률 표시 | 점검 우선순위와 관련 지표를 함께 비교 |
| 현장별 비교표 | 지역·유형·당월 주요 공종·계약금액·누적 및 당월기성액·기성률·계획 및 실제 공정률·공정차이·상태 표시 | 현장별 엑셀 비교를 한 표에서 수행 |
| 기록 펼침 | 같은 비교표 안에서 공사기간·특이사항 분류·기록된 상황·대응 계획 표시. 점검 순위에서 누르면 비교표로 이동해 해당 행 강조·펼침 | 숫자의 배경을 바로 확인 |
| CSV 내보내기 | 현재 선택 월·지역·유형·현장의 원본 15개 열에 계산 결과 4개 열을 추가한 19개 열 제공. 숫자·단위 유지, 엑셀 한글 깨짐 방지 | 사용자 선택 6 반영 |
| AI 설명 | 프로그램이 계산한 지표와 원문 기록을 구분해 전달. 답변에 기준 월·현장·근거 숫자·참고 기록 표시 | 계산과 설명의 근거 확인 |
| AI 추이 설명 | 같은 필터의 선택 월까지 월별 요약 전달. 과거 기록을 설명할 때 해당 월 원문도 전달 | 월별 변화와 기록을 연결 |
| AI 예외 처리 | 자료에 없는 사실은 알 수 없다고 안내. 필터 변경 시 이전 답변 삭제, 이전 범위의 늦은 응답도 표시하지 않음. 연결 실패 시 대시보드·CSV 사용 유지 | 잘못된 범위의 답변과 기능 중단 방지 |

## 계산·표시 기준

| 항목 | 기준 |
|---|---|
| 기성률 | 선택 월·범위의 누적기성액 합계 ÷ 계약금액 합계 × 100 |
| 전체 공정률 | 현장 계약금액에 비례해 비중을 두는 가중평균 |
| 공정차이 | 반올림 전 실제공정률 − 계획공정률. 단위 pp는 두 백분율의 차이 |
| 상태 | -5pp 이하 점검 / -5pp 초과~0pp 미만 주의 / 0pp 이상 정상 |
| 기록 분류 | `issueCategory`는 기록 분류이며 상태 판정에 사용하지 않음 |
| 당월기성액 | 당월 누적기성액 − 바로 전월 누적기성액. 집계 대상 중 하나라도 전월 값이 없으면 전체 당월기성액은 계산 불가 |
| 없는 값과 0 | 첫 달·전월 없음은 ‘계산 불가’. J의 7월처럼 실제 차액이 0이면 0.0 표시 |
| 표시 단위 | 금액 백만원, 비율 %, 차이 pp. 중간 반올림 없이 계산하고 최종값은 소수 첫째 자리까지 표시 |
| 집계 경계 | 여러 달의 계약금액·누적기성액을 합산하지 않음. 자료 없음·분모 없음은 0%로 대체하지 않음 |

## 화면 요약 — 디자인 도구에 전달할 내용

1. PC용 교육용 가상 현장 대시보드. 페이지 4개: 현황 요약 / 현장별 비교표 / 자료 가져오기 / AI에게 묻기.
2. 상태 5개: 자료 없음 / 가져오기 오류 / 점검 대상 없음 / AI 답변 대기 / AI 연결 실패.
3. 첫 화면은 필터 → 큰 숫자 4개 → 점검 순위 → 월별 추이 순서. 큰 숫자 우선은 사용자 선택, 나머지 순서는 `(AI 결정)`.
4. 자료 반영 후 기본값은 2026년 9월·전체. 월·지역·유형·현장 필터를 모든 결과에 공통 적용.
5. 큰 숫자 예시: 기성률 67.2%, 계획 73.2%, 실제 71.2%, 차이 -2.0pp. 금액 백만원, 최종값 소수 첫째 자리.
6. 점검 순위는 D → I → K. 각 행에 공정차이·계획 및 실제 공정률·기성률 표시, 클릭 시 비교표의 해당 행 강조·펼침.
7. 상태는 -5pp 이하 점검, -5pp 초과~0pp 미만 주의, 0pp 이상 정상. 상태명을 글자로 표시 `(AI 결정)`.
8. 비교표에 지역·유형·주요 공종·금액·공정·상태 표시. 펼침 행에 공사기간·상황·대응 계획 표시.
9. 선택 월까지 계획·실제 공정률 선과 월별 기성 막대 표시. 첫 달 당월기성액·자료 없는 지표는 ‘계산 불가’.
10. 가져오기는 검사·미리보기 후 교체. CSV는 19개 열. AI 예시 질문은 “D가 늦어진 이유와 기록된 대응은?” `(AI 결정)`, 답변에 월·현장·근거 표시.
