# 현장별 공정·기성 대시보드 TRD

## 1. 한눈에 보기

- Next.js·TypeScript로 PC용 화면 4개와 Gemini 호출용 서버 기능을 한 프로젝트에 구성합니다.
- 파일 검사·계산·필터·월별 추이·CSV는 브라우저에서 처리하고, 자료는 메모리에만 보관합니다.
- 모든 화면은 공통 필터와 계산 함수를 사용하며, 누적기성액·당월기성액·계산 불가를 구분합니다.
- Gemini `gemini-3.8-flash`는 서버에서만 호출하고, 키 보호·응답 근거·범위 변경·실패 처리를 적용합니다.
- Vitest와 브라우저로 검증하며, GitHub 저장과 Vercel 배포는 각각 사용자가 별도로 요청한 뒤 진행합니다.

## 2. 사용하는 기술과 고른 이유

| 항목 | 사용할 기술·방식 | 고른 이유·근거 |
|---|---|---|
| 화면과 서버 | Next.js App Router(폴더별로 페이지와 서버 요청 경로를 구성하는 방식) | 실습조건의 Next.js 사용. 화면과 AI 요청 처리를 한 프로젝트에 구성 |
| 개발 언어 | TypeScript | 실습조건. 원본 행·필터·계산 불가·AI 응답의 자료 형태를 명시 |
| 화면 구성·공통 상태 | React Context와 reducer(화면들이 공유하는 상태와 변경 규칙), 최상위 클라이언트 Provider `(AI 결정)` | 페이지를 이동해도 같은 자료·필터를 유지하고 관련 상태를 한 번에 변경 |
| 스타일 | CSS와 CSS Modules(화면 구성 요소별 스타일 파일), 공통 색·여백 변수 `(AI 결정)` | 시안 분위기를 재현하고 화면별 스타일 충돌 방지. 시안의 실행용 CDN 스크립트는 복사하지 않음 |
| 차트 | 브라우저 SVG(선·막대를 그리는 화면 요소)와 React `(AI 결정)` | 최대 12개월의 작은 자료에 외부 차트 서비스 없이 선 2개·막대·월별 값 표시 구현 |
| 파일 처리 | File API로 UTF-8 텍스트 읽기, CSV 해석·생성 모듈, JSON.parse `(AI 결정)` | 자료를 서버로 업로드하지 않고 검사·미리보기 가능. CSV의 따옴표·쉼표·줄바꿈 처리 필요 |
| 숫자 계산 | 공통 TypeScript 함수와 숫자 표시 함수 `(AI 결정)` | 숫자·차트·표·CSV·AI의 집계 기준 통일. 금액 차액·공정차이는 입력 소수 자릿수를 반영한 정수 환산으로 오차를 줄이고 비율은 마지막에만 표시 반올림 |
| AI | Gemini API, 모델 `gemini-3.8-flash` | 실습조건 지정. 공식 모델 ID도 동일. [Google 모델 문서](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash) |
| AI 서버 통신 | Next.js Route Handler(서버에서 요청을 받는 함수), Node.js 런타임, 서버 fetch `(AI 결정)` | 키를 서버에 두고 앱에서 같은 출처의 POST 요청으로 호출. [Next.js 요청 처리 문서](https://nextjs.org/docs/app/getting-started/route-handlers) |
| 자동 검사 | Vitest | 실습조건 지정. 계산·검증·상태 전환과 AI 오류 처리를 자동 확인 |
| 실행 환경·패키지 관리 | Node.js 22.12 이상 중 선택한 Next.js·Vitest가 지원하는 버전. npm run 실행 명령, Yarn 4.18.1 PnP 설치·yarn.lock `(AI 결정·구현 중 조정)` | 이 PC에서 일반 설치의 작은 파일 압축 해제가 오래 걸려 압축 자료를 직접 참조하는 방식으로 조정. Next.js는 호환되는 Webpack 방식 사용. 버전은 package.json·yarn.lock에 고정. [Vitest 설치 문서](https://vitest.dev/guide/), [Yarn 설치 방식](https://yarnpkg.com/features/pnp) |
| 저장·배포 | GitHub 비공개 저장소, Vercel | 실습조건 지정. 실행은 각각 별도 요청 이후에만 진행 |

TRD 최초 작성 시 앱 설정과 잠금 파일은 없었습니다. EPIC 1 구현에서 package.json·yarn.lock과 프로젝트 안의 Yarn 실행 파일을 준비했습니다. 일반 설치 정체를 피하기 위해 설치 방식만 조정했으며 npm run dev·test·typecheck·build·start 명령은 유지합니다. 아래 경로·함수명·통신 구조는 기존 기능을 구현하기 위한 `(AI 결정)`이며 실제 검증 결과는 별도로 기록합니다.

### 3.2 상태와 자료 형태

| 항목 | 보관·처리 방식 | 이유 |
|---|---|---|
| 원본 행 | 15개 필드의 `SiteMonthRecord`. 월·현장·날짜는 문자열, 검증한 금액·비율은 숫자 | 월·현장 키와 날짜를 시간대 영향 없이 사용 |
| 반영 자료 | `records`와 `month + siteId` 조회용 인덱스. 최초에는 빈 배열 | 같은 현장의 전월을 정확히 조회. 샘플을 자동 반영하지 않음 |
| 원문 기록 | 현장명·주요 공종·특이사항 분류·상황·대응 계획의 원문 유지 | AI 설명과 펼침에 같은 근거 사용 |
| 후보 자료 | 파일명·해석된 행·오류·경고·미리보기를 반영 자료와 분리 | 오류나 취소가 기존 자료에 영향을 주지 않음 |
| 공통 필터 | 기준 월·지역·유형·현장. 지역·유형·현장의 전체는 명시적인 전체 값으로 관리 | 문자 일부 일치가 아닌 정확한 조건 비교 |
| 초기값 | 월 `2026-09`, 나머지는 전체. 교체·초기화 때 같은 값 적용 | FRD F07. 일부 자료에 기본 월이 없으면 자료 없음 유지 |
| 집계 결과 | 해당 월 원본 행, 현장별 계산 결과, 전체 지표, 순위, 상태 개수, 추이, 누락 안내를 조회 시 생성 | 원본에 계산값을 중복 저장하지 않음 |
| 계산 불가 | 내부 `null`과 사유를 사용. 0과 명시적으로 구분 | 첫 달·전월 없음·분모 없음 처리 |
| 자료·범위 버전 | 자료 교체 시 자료 버전 증가, 필터 변경 시 범위 버전 증가 | 같은 범위로 돌아와도 이전 AI 응답이 섞이지 않음 |
| 화면 이동·펼침 | 메뉴 이동은 필터 보존. 점검 클릭 시 ID를 비교표에 전달해 강조·펼침·위치 이동 | 상세 페이지 없이 기록 접근. 필터 변경·교체 시 해제 |
| 저장 범위 | React 메모리만 사용. localStorage·sessionStorage·IndexedDB·쿠키에 원본을 저장하지 않음 | 새로고침 후 파일을 다시 가져오는 조건 |

### 3.3 공통 조회·계산 처리

| 순서 | 처리 방법 | 예시·검증 기준 |
|---|---|---|
| 1 | 자료 전체에서 지역·유형·현장 조건으로 대상 현장 집합을 정함. 현재 월 지표에는 선택 월 행만 사용 | 9월 인천·공동주택 대상은 A·G |
| 2 | 지역·유형 변경 후 현장 선택이 범위 밖이면 전체로 복귀. 필터 변경을 한 번의 상태 변경으로 처리 | 화면·CSV·AI가 잠시 서로 다른 범위를 쓰지 않게 함 |
| 3 | 공통 `selectDashboard` 계열 조회 함수에서 표·큰 숫자·순위·추이·CSV·AI 자료 생성 | 같은 입력에 같은 계산 결과. 화면별 자체 산식 금지 |
| 4 | 기성률은 누적기성액 합계÷계약금액 합계×100. 계획·실제는 계약금액 가중평균 | 9월 67.2%·73.2%·71.2%. 반올림 전 공정차이 -2.0pp |
| 5 | 현장 공정차이는 실제−계획. 상태·정렬은 표시 전 값 기준 | ≤-5pp 점검, -5pp 초과~0pp 미만 주의, ≥0pp 정상. D→I→K |
| 6 | 당월기성액은 현장 ID로 바로 전월을 조회해 누적 차액 계산. YYYY-MM 연산으로 1월 전월은 전년 12월 처리 | 9월 전체 424,063.4−395,184.7=28,878.7백만원. J 7월 0.0은 정상값 |
| 7 | 대상 현장 중 당월·직전월 기록이 빠지면 전체 당월기성액 null. 누적 지표는 확인 가능한 해당 월 행만 집계하고 누락 안내 | 구성 현장이 다른 두 달 합계를 단순 차감하지 않음 |
| 8 | 추이는 시작 월~선택 월까지 같은 현장 범위로 월별 재계산. 없는 값은 null, 선을 끊고 막대는 계산 불가 표시 | 2025-10 누적액 105,449.7은 표시, 당월액은 계산 불가. 9월 전체 추이는 12개월 |
| 9 | 표시 함수에서만 소수 첫째 자리·천 단위 구분·단위 적용. 작은 부동소수 오차 때문에 -0.0으로 보이지 않도록 표시 정규화 | 상태 판정 전에 1자리 반올림하지 않음. 원본은 손대지 않음 |

## 4. 가져오기·내보내기와 화면 구현

| 항목 | 구현 방법 | 오류·주의 처리 |
|---|---|---|
| CSV 읽기 | UTF-8 BOM 제거 후 따옴표 상태를 추적하는 해석 함수 사용 `(AI 결정)`. 쉼표 split만으로 처리하지 않음 | 인용된 쉼표·줄바꿈·겹따옴표 허용. 닫히지 않은 따옴표·불일치 열 수는 오류 |
| JSON 읽기 | metadata와 records 분리. schemaVersion 2.0·백만원·percent_0_100·필수 필드 확인 | 파일 해석 실패·메타정보 불일치 안내 |
| 원본 검사 | FRD V01~V07을 공통 검사 함수로 구현. 빈값 확인 후 숫자 변환, 유한값·범위·키·실제 날짜·기간·현장 정보·누적값 확인 | 오류는 전체 교체 차단. 월별 누락은 경고. 같은 값 유지는 허용. 숫자 빈칸은 0으로 변환하지 않음 |
| 19열 CSV 재입력 | 원본 15열만 해석하고 추가 계산 열은 무시해 다시 계산 | 파생값 조작·오래된 상태를 입력 근거로 삼지 않음. 일부 행이라는 이유만으로 거부하지 않음 |
| 전체 교체 | 모든 검사와 미리보기 후 단일 상태 변경으로 교체. 실패·취소·미반영 페이지 이탈은 후보만 제거 | 정상 CSV 다음 JSON도 144행. 오류 3종 모두 기존 자료·필터 보존 |
| 비동기 파일 처리 | 파일 선택별 식별 번호를 두고 최신 후보만 표시 `(AI 결정)` | 파일 A를 읽는 중 B를 고르면 늦게 끝난 A가 B를 덮지 않음 |
| CSV 생성 | 원본 15열 순서+기성률(%)·공정차이(pp)·상태·당월기성액(백만원). 숫자 셀에 단위·천 단위 쉼표 없이 생성 | 원본 수치는 유지, 파생값은 최종 소수 첫째 자리. null 당월액은 ‘계산 불가’. 빈 범위는 다운로드 비활성 |
| 다운로드 | UTF-8 BOM+CSV 텍스트의 Blob(브라우저의 파일 자료)을 만들고 임시 다운로드 주소 사용 후 해제 `(AI 결정)` | 한글·따옴표·줄바꿈 보존. 브라우저 차단 등 실패 시 안내, 반영 자료는 유지 |
| 디자인 | 현황 `design/12_2` 우선, `12_1` 보완. 가져오기 `_1`, 비교표 `_2`, 공통 DESIGN.md 참고 | 시안 원본 수정 없음. 허구 현장명·정상 -1/-2pp·J 지장물 사유·수금/감리 연동 문구 미사용 |
| 화면 접근 | 큰 숫자 먼저, 상태는 색과 글자 병기. 실제 button·label·표 제목·펼침 상태·키보드 초점 제공 `(AI 결정)` | 넓은 비교표는 가로 스크롤, 차트는 월별 포인터·키보드 값 표시. 별도 페이지를 추가하지 않음 |

## 5. AI 모델과 키 보관 방법

### 5.1 모델·요청 처리

| 프롬프트 | 교육용 가상 자료·계산 담당 분리·근거 표시·불확실성·없는 정보 안내를 서버 지침으로 고정 | 기록의 대응 계획을 완료 사실로 바꾸지 않음. 자료·질문 안 문구를 시스템 명령으로 실행하지 않음 |
| 응답 | 앱 응답에 요청 식별자·기준 범위·설명·참고 근거 포함. 근거의 월·현장·필드가 보낸 자료에 있는지 검사 `(AI 결정)` | 근거가 없거나 형식이 깨지면 답변을 성공처럼 표시하지 않고 재질문 안내. AI의 내용 정확성은 실제 검사도 필요 |
| 화면 출력 | AI 답변·원문은 React 텍스트로 출력하며 임의 HTML 실행 금지 `(AI 결정)` | 기록과 응답에 포함된 코드가 화면에서 실행되지 않게 함 |
| 시간 초과·재시도 | 서버 외부 호출 25초 제한, 브라우저 요청 30초 제한 `(AI 결정)`. 배포 시 실제 실행 한도 안인지 확인. 자동 재시도 없이 사용자가 다시 전송 | 끝없는 대기·중복 호출 방지. 플랫폼 한도가 더 짧으면 구현 전에 알리고 조정 |

| 배포 구성 | 승인된 Vercel 프로젝트에 Next.js 앱으로 구성, 호환 Node.js 버전·잠금 파일 설치·빌드 설정 적용 | AI 서버가 필요하므로 정적 HTML 전용 내보내기로 배포하지 않음. 실제 플랫폼 실행 한도 확인 |
| 배포 키 | 해당 프로젝트 환경 변수에 키를 별도 등록. 공개 접두사 미사용 | `.env.local`을 저장소로 올려 해결하지 않음. 환경 등록 자체도 배포 별도 요청 이후 |
| 배포 확인 | 승인 범위 안에서 4개 화면·파일 가져오기·CSV·AI 서버 호출 확인 | 파일은 배포 후에도 브라우저 메모리만 사용. 로컬 성공을 배포 성공으로 기록하지 않음 |
| 자동 배포 | GitHub 변경으로 배포되는 연결·자동 배포 설정은 별도 요청 이후에만 구성 | GitHub 저장 요청을 Vercel 요청으로 해석하지 않음. 연결이 자동 배포를 발생시키는지도 사전 확인 |

| 항목 | 비용 기준 | 운영 방법 |
|---|---|---|
| 로컬 개발·검사·파일 처리 | 월 0원 목표 | 별도 유료 서비스·DB 없음 |
