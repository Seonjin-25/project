# 현장별 공정·기성 대시보드 FRD

## 1. 한눈에 보기

- 월·지역·유형·현장 선택을 지표·월별 추이·비교표·CSV·AI에 동일하게 적용합니다.
- 선택 월의 누적기성액과 바로 전월 차액인 당월기성액을 구분하고, 전월이 없으면 계산 불가로 표시합니다.
- 점검 현장을 누르면 비교표의 해당 행을 강조하고 상황·대응 기록을 같은 페이지에서 펼칩니다.
- 가져오기 오류·취소 시 기존 자료를 유지하고, AI 연결 실패 시에도 현황 조회·CSV를 계속 사용할 수 있습니다.
- PRD·원본·검산표를 기준으로 동작을 정하며, 시안의 다른 현장명·숫자·업무 연동 문구는 그대로 사용하지 않습니다.
